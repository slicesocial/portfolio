# Slice Social website

- index.html: the website (design, animations, layout).
- content/clients.json: your clients, text and videos. Edit it in the Pages CMS dashboard.
- content/about.json: your About photo, heading and bio. Edit it in the dashboard.
- media/: videos and images. Files uploaded in the dashboard land here.
- .pages.yml: tells the dashboard which fields to show. You don't need to touch it.

Tip: export client videos for web before uploading (1080x1920 or smaller, H.264 .mp4, ideally under 20 MB each).
